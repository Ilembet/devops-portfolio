### Что выяснилось по ходу

- Если хук pre-commit сам исправил файл, коммит отменяется. Нужно снова выполнить `git add` и `git commit`.
- Коммит без реальных изменений не позволяет открыть pull request.
- Файл `.env` лежит рядом с `docker-compose.yml`, а не в корне репозитория. Пароль базы лучше задавать только латиницей и цифрами, потому что он подставляется в адрес подключения.
- PostgreSQL запоминает пароль в томе при первом запуске. Чтобы сменить пароль, нужен `docker compose down -v`.
- Пакет `docker.io` из Ubuntu конфликтует с `containerd.io` из репозитория Docker. Ставится что-то одно.
