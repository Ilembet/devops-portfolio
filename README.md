# devops-portfolio

Практические работы по DevOps: автоматизация развёртывания, инфраструктура как код, CI/CD, контейнеры, оркестрация и мониторинг. Автор: Василь Илембетов.

English version: [README.en.md](README.en.md).

**Стек:** Linux, Docker и Docker Compose, GitHub Actions, Terraform и Yandex Cloud, Ansible, Kubernetes, Prometheus и Grafana (часть пунктов в плане, см. ниже).

Учебные задания курса Нетологии хранятся отдельно, в репозитории [Homeworks](https://github.com/Ilembet/Homeworks).

## Правила репозитория

- Изменения попадают в `main` только через pull request.
- Ветки называются `feat/...`, `fix/...`, `docs/...`; сообщения коммитов начинаются с `feat:`, `fix:`, `docs:`.
- CI работает с первого коммита: линтеры, поиск секретов, проверка Terraform.
- Секреты лежат только в `.env` (в git не попадает); в репозитории есть `.env.example`.
- Всё, что описано в README, лежит в репозитории и запускается одной командой.

## Структура

| Папка | Что внутри |
| --- | --- |
| `projects/` | Приложения и сервисы, на которых отрабатываются инструменты |
| `infra/` | Terraform, позже Ansible и Helm |
| `docs/` | Архитектура, runbook-и, разборы инцидентов |

## Локальная работа

Один раз установи [pre-commit](https://pre-commit.com/) и включи хуки:

```bash
pip install pre-commit
pre-commit install
```

После этого `gitleaks`, `yamllint`, `shellcheck` и `markdownlint` запускаются перед каждым коммитом.
